# راهنمای جامع افزونه کروم AG AntiVPN Selective Router

افزونه **AG AntiVPN Selective Router** به شما این امکان را می‌دهد که هنگام روشن بودن **OpenVPN** روی لپ‌تاپ خود، به‌صورت انتخابی و هوشمند تعیین کنید کدام سایت‌ها یا تب‌های کروم از VPN استفاده کنند و کدام سایت‌ها بدون VPN (مستقیماً با اینترنت عادی لپ‌تاپ) باز شوند.

---

## 🌟 امکانات و قابلیت‌های اصلی

- **سوئیچ سریع برای هر تب**: با کلیک بر روی آیکون افزونه در هر تب، با یک کلیک گزینه `غیرفعال‌سازی VPN برای این سایت` را بزنید تا آن دامنه فوراً بدون VPN باز شود.
- **نشانگر دیداری (Badge)**:
  - 🟢 **`NO-VPN` (سبز)**: این تب بدون عبور از VPN و با اینترنت عادی باز می‌شود.
  - 🔵 **`VPN` (آبی)**: این تب از طریق OpenVPN متصل است.
  - ⚪ **`OFF` (خاکستری)**: افزونه خاموش است.
- **بای‌پاس خودکار دامنه‌های ایرانی (`.ir`)**: شناسایی هوشمند و عدم عبور دامنه‌های ملی از VPN برای جلوگیری از مسدودی یا افت سرعت سایت‌های داخلی.
- **پشتیبانی از دامنه‌های الگویی (Wildcards)**: قابلیت تعریف الگوهایی مثل `*.ir` یا `*.bank.com`.
- **لیست‌های آماده (Presets)**: امکان افزودن یک‌کلیکه بانک‌ها و سایت‌های خبری پرکاربرد ایرانی به لیست بای‌پاس.
- **پشتیبانی از پروکسی کمکی لوکال (Local Interface Adapter)**: جهت بای‌پاس کامل کارت شبکه TUN/TAP اوپن وی پی ان در ویندوز.

---

## 🛠️ مراحل نصب و راه‌اندازی در مرورگر کروم

1. مرورگر **Chrome** را باز کرده و آدرس `chrome://extensions` را در نوار آدرس وارد کنید.
2. گزینه **Developer mode** را در بالای سمت راست صفحه روشن کنید.
3. بر روی دکمه **Load unpacked** کلیک کنید.
4. پوشه پروژه (`c:\Users\rkhos\Projects\AGchromeantivpn`) را انتخاب کنید.
5. افزونه **AG AntiVPN Selective Router** با موفقیت بارگذاری می‌شود.

## 💻 راهنمای اجرای اسکریپت کمکی لوکال (برای بای‌پاس OpenVPN سیستم‌عامل)

هنگامی که OpenVPN روی ویندوز روشن است، تمامی پکت‌ها را از کارت شبکه مجازی خود (TUN/TAP) رد می‌کند. برای اینکه ترافیک سایت‌های بای‌پاس شده واقعاً از کارت شبکه اصلی شما (Wi-Fi یا کارت شبکه لپ‌تاپ) عبور کند و OpenVPN دور زده شود:

### روش اول: اجرای اسکریپت پایتون (توصیه شده)
پوشه پروژه را در ترمینال یا CMD باز کرده و دستور زیر را اجرا کنید:
```bash
python helpers/local_adapter_proxy.py
```

### روش دوم: اجرای اسکریپت Node.js
اگر پایتون ندارید و Node.js روی سیستم نصب است:
```bash
node helpers/local_adapter_proxy.js
```

> **نکته:** اسکریپت فوق روی پورت `127.0.0.1:8888` قرار گرفته و ترافیک بای‌پاس شده افزونه را مستقیماً از کارت شبکه Wi-Fi/Ethernet شما فرستاده و OpenVPN را دور می‌زند.

## 📂 ساختار فایل‌های پروژه

- `manifest.json`: فایل پیکربندی اصلی Manifest V3 افزونه.
- `background/service-worker.js`: مدیریت PAC Script، تنظیمات پروکسی کروم و نشانگر تب‌ها.
- `popup/`: رابط کاربری سریع و شکیل پاپ‌آپ افزونه.
- `options/`: صفحه تنظیمات پیشرفته (افزودن دامنه‌ها، ایمپورت/اکسپورت).
- `helpers/`: اسکریپت‌های پایتون و نود کمکی برای بای‌پاس کارت شبکه OpenVPN ویندوز.
- `icons/`: آیکون‌های گرافیکی افزونه.
